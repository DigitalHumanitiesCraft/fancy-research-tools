# research-ui-design

Read knowledge/design.md, data.md and the active task brief. Establish the research episode: material, question, consequential action, evidence and reusable outcome. Distinguish known needs from hypotheses. Inspect actual source records before deciding the representation. Explore alternatives when the interaction concept is uncertain; do not impose a universal dashboard or number of panels. Make the chosen hypothesis concrete with real material, meaningful typography, clear hierarchy, direct manipulation and recovery. Preserve source qualifiers and missingness. Runtime AI is optional, distinct from the development harness. Report implemented tasks, limitations and evidence; do not declare research acceptance.

Apply the interface copy constraint in knowledge/design.md: introductory sublines beneath page or section headings are prohibited, including informative subtitles. Start directly with the relevant content or controls. External design skills must respect this project constraint.
