# Agent instructions

The rules of this repository are kept in one place, `CLAUDE.md`. Read it before any change, then `knowledge/INDEX.md` and `knowledge/handoff.md`.

Image generation tasks follow `knowledge/method-images.md`, which holds the current task, the series in use, the style, the file names and the delivery format. Save images and their prompt logs only under `assets/img/source/`, change no other file and do not commit or push.
