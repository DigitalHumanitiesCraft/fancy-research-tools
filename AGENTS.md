# Agent instructions

The rules of this repository are kept in one place, `CLAUDE.md`. Read it before any change, then `knowledge/INDEX.md` and `knowledge/handoff.md`.

Image generation tasks, if requested, follow `knowledge/design.md`, section "Generated images", which holds the rules, the delivery format and the prompt per variant. Save each image as `assets/img/source/motif-<slug>.png` and note prompt, model and date in `assets/img/source/motif-<slug>.txt`. Change no other file and do not commit or push.
