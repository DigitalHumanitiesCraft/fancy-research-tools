# Benndorf to Schuchardt, 14 February 1879

The reading case uses the real letter transcription already supplied with teiCrafter. Friedrich August Otto Benndorf wrote the letter in Vienna to Hugo Schuchardt. The edition identifies it as 02-00932, edited by Hubert Szemethy (2022), in Bernhard Hurch (ed.), *Hugo Schuchardt Archiv*.

- [Edition and facsimile](https://gams.uni-graz.at/o:hsa.letter.7711)
- [Persistent identifier](https://hdl.handle.net/11471/518.10.1.7711)
- [Upstream transcription and notice](https://github.com/DigitalHumanitiesCraft/teiCrafter/tree/5e76308/docs/data/editor/hsa-7711)

The letter text is public domain according to the retained upstream notice: the letter dates from 1879 and Benndorf died in 1907. That notice does not grant a blanket licence for the edition. The edition's footnote texts, source XML apparatus and images are excluded. The upstream plaintext has removed footnote numerals and retained the `|2|` page marker. The exact upstream local-copy bytes and its notice are retained under `raw/`.

`sources.json` normalizes CRLF or CR line endings to LF for native browser selection offsets. It makes no other textual change. The raw-file and displayed-text SHA-256 hashes identify these distinct representations. Offsets in notebooks count UTF-16 code units in the displayed text. The generator supplies source roles and rights as fixed metadata recorded from the upstream notice. `generate.mjs --check` reproduces the output from the retained letter bytes and those configured metadata, then compares it with `sources.json`. It checks the text transformation, hashes and output agreement. It does not read the notice or verify the scholarly transcription against a facsimile.

The categories Person, Place, Research topic and Editorial question are annotation choices for this working case. They do not constitute a validated ontology or an automatic identification. An annotation's self-declared creator and source-fit review are separate from the historical author, modern editor and publisher of the letter.
