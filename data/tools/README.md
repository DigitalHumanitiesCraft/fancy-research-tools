# Tool directory

`catalog.json` is the maintained input to `scripts/build-gallery.mjs`. It records task groups, explicit launch destinations, material, actual screenshots, source repositories and access limits. The [DHCraft portfolio](https://dhcraft.org/fancy-research-tools/) supplied the starting inventory. Live pages and local project sources were selectively inspected on 2026-10-10. A reachable page and an exercised sample are distinct from full application acceptance.

The gallery integrates existing public applications through ordinary navigation. Their runtime code, credentials and services remain at their own hosts. The local comparison, metadata and annotation tools have separate source and recovery contracts. Agentic Edition Pipeline is a project template, so its entry opens the repository and knowledge rather than claiming an immediately running application.

## Previews

The PNG files under `public/previews/` are captures of rendered applications. No generated mockup is used. The local annotation capture contains an unsaved selection with an empty interpretation, no asserted creator and no recorded review. It does not fabricate research evidence.

External previews retain the source application's visual state. They do not imply that its design was rewritten or approved here. Source data, edition apparatus, scans and provider credentials from those applications have not been bundled, apart from the separately documented public letter transcription and CC0 correspondence metadata. Internal workflow research informed task and provenance decisions without copying ACTIVE-WORK or institutional data into this directory.
