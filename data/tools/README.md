# Tool directory

`catalog.json` is the maintained input to `scripts/build-gallery.mjs`. It records task groups, explicit launch destinations, material, actual screenshots, source repositories and access limits. The [DHCraft portfolio](https://dhcraft.org/fancy-research-tools/) supplied the starting inventory. Live pages and local project sources were selectively inspected on 2026-10-10. A reachable page and an exercised sample are distinct from full application acceptance.

The gallery offers five research-task entries. Collection Explorer opens the local photograph tool. Capture and encode opens the real SZD preparation guide for teiCrafter. Analyse correspondence opens CorrespExplorer. Review and correct opens the local Klawiter curation guide, with its public reading interface identified separately. Build editions opens the SZD guide with the Agentic Edition Pipeline template as a secondary resource. Existing application runtimes, credentials and services remain with their projects. Earlier comparison, metadata and annotation workspaces remain technical examples in development guidance.

## Previews

The PNG files under `public/previews/` are captures of rendered applications. No generated mockup is used. A screenshot of a public reading interface is labelled as such and does not claim to show local correction controls. The local annotation capture contains an unsaved selection with an empty interpretation, no asserted creator and no recorded review. It does not fabricate research evidence.

External previews retain the source application's visual state. They do not imply that its design was rewritten or approved here. Provider credentials and institutional working copies are excluded. Reused source material is separately documented in the public letter, correspondence and SZD source packages. The SZD package retains source-specific rights and remote facsimile references without bundling scans. Internal workflow research informed task and provenance decisions without copying internal coordination documents or institutional data into this directory.
