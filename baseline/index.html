About this tool

Explore musical-instrument catalogue metadata from Met Open Access. Groups and table rows describe the same filtered selection. Selecting a category narrows that selection.

Dataset and limits

This convenience sample contains the 60 lowest-ID records from department 18. It is not representative of the museum collection or musical history. Empty fields indicate missing catalogue metadata, not historical absence.

Date sorting uses the catalogue's earliest year. Catalogue bounds are not exact creation dates. Missing values sort last in either direction. Exports preserve source values and provenance.
