# fancy (research) tools!

Website for a service of Digital Humanities Craft OG: custom tools that speed up a concrete workflow, for research and cultural heritage institutions as well as companies and public administration, plus adaptable tools and the methods and frameworks behind them.

Static HTML and CSS without a build step and without JavaScript, served by GitHub Pages from the repository root.

Several design variants share one content source. `index.html` is the main variant (Prisma). The variants `dhcraft/`, `edition/`, `labor/` and `raster/` each add one theme stylesheet under `assets/` and, together with the overview page `varianten/`, are generated by `node tools/build-variants.cjs`, so run that script after every content change. `tools/shoot-variants.cjs` renders the preview images and `tools/check.cjs` runs the accessibility, layout, image and link checks. Both need an existing Playwright installation.

Project knowledge lives in [knowledge/INDEX.md](knowledge/INDEX.md).
