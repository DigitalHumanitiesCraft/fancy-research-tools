# fancy (research) tools!

Website for a service of Digital Humanities Craft OG: custom tools that speed up a concrete workflow, for research and cultural heritage institutions as well as companies and public administration, plus a set of research tools that can be adapted to a project.

Static HTML and CSS without a build step and without JavaScript, served by GitHub Pages from the repository root.

Project knowledge lives in [knowledge/INDEX.md](knowledge/INDEX.md).
